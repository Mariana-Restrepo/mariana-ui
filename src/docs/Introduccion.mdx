# mariana-ui

Sistema de diseño de **Mariana Restrepo Barrientos** para aplicaciones web y móviles.

## Dos estilos, un mismo sistema

Cada estilo funciona en **modo claro y oscuro**. Usa los selectores **Estilo** y **Tema** de la barra superior para verlos.

## Cómo se usa

```html
<div data-style="creativo" data-theme="dark">
  …tu aplicación…
</div>
```

```tsx
import '@mariana-restrepo/mariana-ui/styles.css'
```

## Principios

1. **Accesible por defecto.** WCAG 2.2 AA: contraste suficiente, foco siempre visible y navegación por teclado.
2. **Tokens antes que valores sueltos.** Los componentes solo leerán tokens semánticos (`--mr-color-primary`, `--mr-radius-control`…). Cambiar de estilo es cambiar tokens, no componentes.
3. **Web y móvil.** Usa el selector de vistas para revisar cada pantalla en móvil, tablet y escritorio.

## Estado

Esta es la **base del sistema**: tokens y documentación. Los componentes se construirán sobre ella, paso a paso.
